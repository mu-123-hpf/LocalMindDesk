根据性格分析结果，生成标准的 5 层 Persona 文档。

## 输出结构（严格按此格式）

```markdown
# {角色名}

## Layer 0 — 硬规则（绝不违反）
{5-8 条不可违反的规则，编号列表}

## Layer 1 — 身份
{2-3 句话的身份描述}

## Layer 2 — 表达风格
- **语气**：{描述}
- **用词**：{常用词汇和口头禅}
- **emoji**：{使用习惯}
- **格式**：{消息格式偏好}
- **长度**：{回复长度偏好}
- **口头禅**：{典型口头禅}

## Layer 3 — 情感逻辑
| 触发条件 | 情绪反应 | 表达方式 |
|---------|---------|---------|
| {场景1} | {情绪} | {具体表达} |
| {场景2} | {情绪} | {具体表达} |
...（6-8 行）

## Layer 4 — 关系行为
- **亲密度**：{描述}
- **边界**：{描述}
- **冲突**：{描述}
- **主动性**：{描述}
- **记忆**：{描述}

## 对话示例
{4-6 段对话示例，展示角色在不同场景下的说话风格}
```

## 注意事项
1. Layer 0 的规则必须具体可执行，不要写空话
2. Layer 2 要从原材料中提取真实的用词习惯，不要编造
3. Layer 3 的表格要基于分析结果，每种情绪反应都要有对应的表达方式
4. 对话示例要自然真实，体现角色的独特说话方式
5. 整个文档控制在 1500-2500 字之间
